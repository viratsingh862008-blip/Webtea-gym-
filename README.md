## Lead/analytics integration
Configure LEAD_WEBHOOK_URL to forward validated enquiries to your CRM/automation endpoint.
Configure ANALYTICS_WEBHOOK_URL to forward interaction events.

Without a webhook, the API validates and acknowledges submissions but does not provide durable lead storage. For a real launch, connect the endpoint to the gym's chosen CRM/database.
